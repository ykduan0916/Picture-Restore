# 首轮执行清单

首轮为 S0。目标是把最大的产品与工程风险变成可复核证据，再进入完整产品开发。此清单中的负责人为职能责任，不代表已经有相应人员或自动委派了其他 Agent。

## 立即可开始的工作

W-02 契约校验和 W-03 本地骨架不需要真实模型账户。W-04/05/08 可使用假供应商证明状态、权限和恢复协议。不得把假供应商的成功作为图像质量通过。

W-01、W-09 需要真实素材与模型条件。输入尚未明确时保留依赖，不擅自使用其他项目的密钥、素材或历史选择。

## 单个工作项的完成标准

- 产物可定位，有运行或复核方式；截图不能替代源文档和状态证据。
- 必要的行为测试通过，尤其是权限、版本冲突、预算和状态恢复；不为纯文档或简单样式增加机械测试。
- 失败路径可解释，未执行检查显式标注。
- 更新对应契约、决策和受影响验收用例。
- 不包含密钥、无授权素材或误导性的“生产就绪”结论。

## S0 演示脚本

1. 使用选定 SKU 的授权原图，创建白底、场景、促销三项任务。
2. 查看任务契约，确认价格来自输入、商品属性被保护。
3. 展示设计与素材准备的独立产物，以及汇合后的计划。
4. 展示一次被检测到的可修复问题和有限返工，不伪造模型质检结果。
5. 修改促销价格，验证背景与商品层未变，也未新增生图费用。
6. 注入一次中断并恢复，说明哪些状态来自数据库、哪些外部状态仍未知。
7. 在任务执行期间人工编辑文档，验证旧产物不能覆盖新版本。
8. 导出并打开图片与清单；记录费用、耗时、限制和质量结果。

没有真实供应商时可演示 2、3、5、6、7 的协议能力，但不得宣称全部脚本或 G0 完成。
