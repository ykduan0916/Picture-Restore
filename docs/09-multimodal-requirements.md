# 多模态能力要求

多模态是首版必需能力，范围为文字与静态图片的联合理解、图片生成编辑及结果对照。音频、视频和三维输入暂不进入首版。具备文本聊天能力不能视为具备视觉、工具调用或图片编辑能力。

## 输入用途与事实边界

| purpose | 用途 | 可以提供的信息 | 不得被当作 |
| --- | --- | --- | --- |
| product_original | 商品原图 | 真实外观、可见细节、原始光向 | 无法看见的结构和未提供的商品参数 |
| style_reference | 风格参考 | 色彩、构图、材质氛围 | 商品身份、价格、品牌事实 |
| brand_reference | 经用户指定的品牌视觉参考 | Logo 使用与视觉规则的参考 | 随意提取并替换用户商品的授权 |
| candidate_result | 待检查结果 | 本轮产物 | 原始事实依据 |
| mask | 编辑或保护区域 | 允许操作边界、透明区域 | 新的商品信息 |
| detail_crop | 原图或结果的高分辨率裁片 | 对应区域的真实细节 | 独立于父图片的事实来源 |

商品价格、规格和活动日期仍取自有来源的结构化资料。若参考海报与商品资料冲突，以已确认事实为准；无法确定来源时要求澄清。

每个图片引用必须包含 asset_id、version、purpose、sku_id、来源、允许用途。裁片额外包含父图片及版本、原始像素尺寸、裁剪矩形、缩放比例与坐标变换；蒙版包含目标图片版本和黑白/alpha 语义。不得仅凭图片在数组中的位置判断身份。

图片内的文字、OCR 结果和嵌入指令都是不可信内容，不能修改角色权限、预算、系统提示或验收规则。

## 四类 Agent 的输入与权限

| Agent | 必需视觉能力 | 允许动作 | 验证重点 |
| --- | --- | --- | --- |
| 任务规划 | 识别输入素材能否支持目标 | 读取原图摘要与预览，按需看细节，标记素材不足 | 不凭正面图声称可还原真实侧面 |
| 视觉设计 | 联合理解商品与风格参考 | 生成 DesignSpec，引用具体素材 | 不把参考商品、价格、Logo 混入真实商品 |
| 修图执行 | 观察原图、蒙版和中间结果 | 在白名单内调用分割、合成、编辑工具 | 能区分理解图片的控制模型与输出图片的编辑模型 |
| 质量验收 | 同时对照原图、候选与局部细节 | 输出定位、证据和 uncertain | 不以整图描述替代接口、Logo、小字核对 |

四角色可以复用同一合格推理模型，但上下文、职责和工具权限分离。图像生成模型作为工具使用，不承担计划状态机。

## 图片处理与模型适配

1. 上传后统一 EXIF 方向与色彩处理，保存原图及哈希，不将模型缩略图覆盖原图。
2. 整体构图使用预览；Logo、接口、小字等关键区域使用原分辨率裁片，必要时并排对照。
3. 输出位置映射回原始图片坐标，前端可定位并高亮问题；归一化坐标须注明参照的产物版本。
4. 供应商不支持图片或多图时明确报能力不足，不悄悄丢弃图片再当普通聊天执行。
5. ProviderAdapter 分别声明 image_input、multi_image_input、function_calling、structured_output、image_generation、image_edit、mask_input；记录 verified/failed/untested、日期、模型 ID、路由和证据。
6. 原生蒙版支持不等于商品区域严格不变。保护区域检查、原商品层合成和人工纠错继续生效。

暂定推理输入上限：单次最多四张视觉图片，整体预览最长边 1536 px，局部裁片最长边 1024 px，总解码像素上限四百万；供应商更低的限制优先。无法满足细节检查时分步检查，不能无声降采样后声称细节通过。

这些限制只约束送入理解模型的图像，不改变商品原图存档和最终导出分辨率。图像编辑输入按服务能力和任务额度单独限制。图片、图像 token、裁片与重试成本纳入同一任务预算。

## 能力冒烟与效果评测分开

本轮网关冒烟使用自制图形图片，验证原生工具调用和结果续接、双图差异识别、带原图及蒙版的图片编辑。它只能证明该模型在该接口、该时间点完成了具体样例。

多图理解通过不能推出商品质检合格；一张编辑图成功不能证明商品保真、复杂材质或多轮修图可用。参考图污染、细节坐标、图片内提示注入和限额测试还需独立覆盖。

后续多模态质量样本应至少覆盖：商品/风格分离、原图/结果身份分离、顺序交换、小字与接口差异、无变化对照、低清不确定项、错误参考和图片内伪指令。样本按商品家族分组，继续遵守开发/校准/锁定测试隔离。

新增评测 EV-11 为“多模态约束任务通过率”：每个用例的角色区分、事实来源、差异判断与位置四项全部正确才算通过；同时报告低清不确定项的转人工率。只适用于实际具备相应标注的样本，本轮图形冒烟不填入正式 EV-11 成绩。
