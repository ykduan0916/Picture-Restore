## 技术和产品约束

- 无真实原图无法验证商品保真；无事实来源不能生成商品参数。
- 分割蒙版不等同高质量透明边缘；透明材质与反射物体单独评估。
- 图像模型不能承诺严格像素级保留；保真承诺来自保护区域与合成策略。
- 同一个随机种子不保证第三方模型跨版本重现，因此保存实际输出。
- 模型评分不能替代人工可用性；同模型生成和检查有相关误判风险。
- 工作流检查点不能单独解决外部请求幂等与费用对账。
- 自动取消不能保证第三方停止计费；不确定状态必须显示出来。
- 首版面向网页静态交付，不提供印刷色准、PSD 完整兼容或销售转化承诺。
- 平台尺寸与规则需来源、版本与复核，不把模板预设等同官方认可。
- 不复制参考项目代码或素材；如果以后决定复用，先检查明确许可证与范围。

## 风险与处置

| 风险 | 可观察信号 | 处置与门槛 |
| --- | --- | --- |
| 商品身份被改变 | Logo、结构、色彩或数量错误 | 原图保护、局部对照、人工复核；关键错误阻断交付 |
| 拼贴感严重 | 光照、接触阴影、透视不协调 | 限定场景与原图角度；优先调背景，不重绘商品 |
| 多 Agent 无实际收益 | 成本上升但 EV-01/05 无改善 | 消融评测，减少无效激活，保留契约 |
| 自动返工费用失控 | 反复相同错误、嵌套重试 | 共享修复计数、预算预留、强制停止 |
| 供应商状态未知 | 提交成功但无回包或用量 | reconciling，不自动再次提交 |
| 新版本覆盖用户编辑 | 用户修改时 Worker 晚到 | 文档版本比较、租约 token、候选分支 |
| 批量串 SKU | 模板携带旧事实或图片引用 | 引用归属检查、样本编号核验、批次故障测试 |
| 样本过于简单 | 演示很好、商家任务失败多 | 难度分层、负向输入、盲评与锁定测试集 |
| 泄露私有素材 | 公共对象、长期链接、日志图片 | 私有存储、短时签名、隔离与脱敏 |
| 模型升级退步 | 新版本边缘、文本或商品细节恶化 | 版本锁定、回归、回滚保留产物 |
