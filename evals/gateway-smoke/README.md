# 网关能力冒烟

实际调用用户为本项目提供的网关，验证模型别名在当前凭据下的工具调用、结果续接、多图理解和蒙版编辑能力。首轮结果见 [实测报告](../../docs/10-gateway-smoke-results.md)。

## 运行

从项目根目录执行；命令会实际调用模型并可能产生费用，不属于离线测试。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r scripts/requirements-smoke.txt
.venv/bin/python scripts/gateway_smoke.py --base-url http://192.168.11.88:3000 --suite all
```

密钥通过不回显输入读取，仅驻留进程内存。不放命令行参数、环境文件或结果 JSON。脚本限定到用户提供的网关，禁止认证请求自动重定向。每次执行建立独立的上海时区时间戳目录。

可选择 core 或 edit 子集。默认 all 最多十二条请求：三个控制候选各最多三条，三个图像候选各一条；本轮 Luna 工具调用失败，未执行续接，所以实际为十一条。脚本另设十八条硬上限以防后续改动失控。所有推理输出上限显式设置，图片编辑 n=1、quality=low、1024×1024，无自动重试。该上限控制请求数量，不等于已知的人民币费用上限。

工具为本地无副作用的 lookup_export_profile。验证工具名、参数，并要求模型在收到结果后准确回传临时随机 receipt，避免把仅输出工具名或编造结果判作通过。

多图样例为自制图形，题目不提供预期答案，核对两图右侧颜色、第二张新增形状及颜色、未变主体形状和标签共六项。square 与 rectangle 对方形允许等价。只有六项都正确才记 pass。

编辑样例为自制瓶状图形与 alpha 蒙版，透明区可编辑，实心区保护。成功返回后需要独立看图评审；数值差异只验证特定保护区像素变化，不能替代对真实商品的视觉验收。

## 证据

- requests.json：脱敏请求与响应、HTTP 状态、延迟、用量与请求 ID，图片 Base64 不内嵌。
- summary.json：各项判断、请求次数、实际金额未知标记。
- fixtures：每次运行实际使用的原图与蒙版。
- 单模型 JSON：具体能力判断；若生成图片成功，另保存 PNG 并待视觉复核。

输入图片由脚本生成，无真实商品和第三方素材。一次冒烟成功仅表示该样例通过。未测试模型不能判为不支持；503 无可用通道不能判为模型固有能力不足；不存在的用量或价格不得填零。
